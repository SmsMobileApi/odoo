Required service and transparent data exchange

This module requires a SMSMobileAPI account, an active API key and the official SMSMobileAPI mobile application connected to that account. Availability depends on the SMS and call permissions enabled by the user in the mobile application.

Before any connection test, send, synchronization, mobile permission check or webhook ingestion, an Odoo manager must read and actively accept the in-app disclosure. Consent time, user and disclosure version are recorded. Withdrawing consent disables automatic synchronization and webhook ingestion.

Data transmitted to api.smsmobileapi.com

  • Account API credential used to authenticate the request
  • Recipient phone number, SMS text, selected mobile identifier and send options when sending

Data retrieved from api.smsmobileapi.com for enabled channels

  • SMS text, correspondent phone number, direction, delivery state and timestamps
  • Missed, incoming and outgoing call-log metadata: phone number, time, type and duration
  • Connected-mobile identifiers, connection status, application version and permission state

No call audio is accessed or transferred. Data is exchanged over HTTPS to send SMS from the connected mobile and synchronize only the activity selected by the Odoo administrator.

Privacy information is available in the SMSMobileAPI privacy policy at smsmobileapi.com/privacy-policy/.

Clear setup and channel-by-channel control

Connect with the account API key, accept the disclosure, select the exact channels to synchronize, and verify mobile permission status directly in Odoo.

Security by design

  • Explicit opt-in before any external data exchange
  • Server-side API key restricted to managers
  • HTTPS host pinned to api.smsmobileapi.com
  • HMAC-signed webhook events with timestamp validation
  • Exact, ambiguity-safe phone matching
  • Multi-company access rules and record isolation

Compatibility

  • Odoo 17 Community and Enterprise
  • Odoo.sh and self-hosted / On-Premise deployments
  • Not compatible with standard Odoo Online because the module contains Python code
